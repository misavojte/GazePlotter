# About & Citation

GazePlotter is a free, open-source tool for eye-tracking visualization and analysis that runs entirely in your browser. No registration, no ads, and no data sent to a server. Just open science.

## How to cite

If GazePlotter helps your research, please cite the article that describes it. Citations keep the tool funded and help other researchers find it.

> Vojtechovska, M., Popelka, S. GazePlotter: An open-source solution for the automatic generation of scarf plots from eye-tracking data. *Behav Res* **58**, 85 (2026). [https://doi.org/10.3758/s13428-026-02959-5](https://doi.org/10.3758/s13428-026-02959-5)

```bibtex
@article{vojtechovska2026gazeplotter,
  author  = {Vojtechovska, Michaela and Popelka, Stanislav},
  title   = {GazePlotter: An open-source solution for the automatic generation of scarf plots from eye-tracking data},
  journal = {Behavior Research Methods},
  volume  = {58},
  pages   = {85},
  year    = {2026},
  doi     = {10.3758/s13428-026-02959-5}
}
```

The [figure export](/docs/export/figures/) dialog also offers the reference with a **Copy citation** button, so it is at hand when a figure goes into a paper. Read the [full article](https://link.springer.com/article/10.3758/s13428-026-02959-5) at Springer.

## Who makes GazePlotter

GazePlotter is created by [Michaela Vojtechovska](https://vojtechovska.com) under the supervision of [Stanislav Popelka](https://www.geoinformatics.upol.cz/lide/stanislav-popelka/?lang=en) at the [Eye-tracking Laboratory](https://eyetracking.upol.cz) of Palacký University Olomouc. It lets researchers and non-programmers visualize eye gaze data without writing code. The tool is and will remain free.

## Report a bug or request a feature

Help improve GazePlotter: report issues, request new visualizations, or contribute code on [GitHub Issues](https://github.com/misavojte/GazePlotter/issues). Community feedback keeps GazePlotter stable and up to date.

## Supported data

GazePlotter reads exports from all major eye-tracking platforms: [Tobii Pro Lab](/docs/upload-data/tobii-pro-lab/), [SMI BeGaze](/docs/upload-data/smi-begaze/), [Gazepoint](/docs/upload-data/gazepoint/), [OGAMA](/docs/upload-data/ogama/), [Varjo](/docs/upload-data/varjo/), and [Pupil Cloud](/docs/upload-data/pupil-cloud/), plus [custom CSV](/docs/upload-data/custom-csv/) files from any other eye tracker. See [Supported File Formats](/docs/upload-data/) for details.
